# Новогодняя комната — режиссёрский тритмент

Одностраничный сайт-презентация. Каждый слайд — остановка «камеры» у предмета в детской комнате. Переход между слайдами — полёт камеры по общему плану: отъезд, пролёт, наезд на следующий предмет.

Только статика: HTML + CSS + JavaScript, без сборки. GSAP и шрифты лежат локально, поэтому сайт работает офлайн.

## Запуск

- **Локально:** двойной клик по `index.html`. Проверено в Chrome; Firefox, Safari и Edge тоже должны работать.
- **Онлайн:** GitHub Pages, см. раздел «Публикация на GitHub Pages».

## Управление

| Действие | Как |
|---|---|
| Вперёд | колесо вниз, `→` `↓` `PageDown` `Space`, свайп влево или вверх, кнопка `›` |
| Назад | колесо вверх, `←` `↑` `PageUp` `Shift+Space`, свайп вправо или вниз, кнопка `‹` |
| К любому слайду | клик по точке внизу (на узких экранах точек нет, только счётчик) |
| Первый / последний слайд | `Home` / `End` |
| Полный экран | `F` |
| Музыка вкл/выкл | `M` или кнопка в правом верхнем углу |
| Режим калибровки | `D` или `index.html?debug=1` |

Текущий слайд хранится в адресе (`index.html#fireplace`). После перезагрузки откроется он же. Музыка в этом случае включится после первого клика: браузеры не дают запускать звук без действия пользователя.

## Структура

```
assets_src/          исходники (картинки, музыка) — не трогать руками
  content/           картинки и видео для слайдов (референсы, аниматики)
assets/              сжатые файлы — создаёт scripts/optimize.ps1
  master/            мастер-кадр, нарезанный на тайлы, + tiles.js
  content/           сжатый контент слайдов
fonts/               Playfair Display и Nunito (кириллица + латиница)
vendor/gsap.min.js   библиотека анимации
scripts/optimize.ps1 сжатие ассетов через FFmpeg
index.html
style.css
config.js            слайды, тексты, координаты камеры, настройки
app.js               движок: камера, переходы, навигация, звук
debug.js             режим калибровки
```

## Сжатие ассетов

Нужен FFmpeg в `PATH`. Запускать из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\optimize.ps1
```

Скрипт обрабатывает только изменённые файлы. Чтобы пересобрать всё, добавьте `-Force`. В конце он выводит таблицу «было / стало».

Что делает скрипт:
- **Мастер-кадр:** WebP с качеством 88 в исходном разрешении, нарезанный на тайлы 2048 px в двух уровнях (полный и ½). Плюс лёгкая копия `master-2k.webp` для быстрого старта. Движок подгружает только те тайлы, куда смотрит камера. Если мастер уже 4000 px, скрипт предупредит.
- **Крупные планы и дверь:** WebP с качеством 82, ширина до 2560 px. Кириллические имена превращаются в slug по таблице в начале скрипта. Новые файлы получают slug транслитерацией: `Книжная полка.png` → `knizhnaya-polka.webp`.
- **Музыка:** `music.mp3` (160 kbps) и `music.ogg` (Opus). Берётся первый аудиофайл из `assets_src/`.
- **Контент** из `assets_src/content/`: картинки → WebP шириной до 1920 px, видео → MP4 (H.264) плюс постер `*.poster.webp`. Имена тоже транслитерируются: `Референс 1.png` → `assets/content/referens-1.webp`.

## Как добавить контент

Все тексты и картинки задаются в `config.js`, в массиве `slides`. Сырой HTML не нужен: у каждого слайда есть поле `content`, и его шаблон выбирается через `content.layout`. Незаполненные поля шаблон просто не выводит.

### Поля слайда

```js
{
  id: "fireplace",          // имя в адресе: index.html#fireplace
  bg: "fireplace",          // крупный план: assets/fireplace.webp (null — общий план комнаты)
  camera: { x, y, w, h },   // рамка остановки на мастер-кадре (размечается в калибровке)
  theme: "dark",            // "dark" — светлый текст на тёмном фоне, "light" — тёмный на светлом
  layout: "center",         // где на фоне свободно: "center" | "left" | "right"
  backdrop: "strong",       // (необязательно) плотнее подложка под текстом на пёстром фоне
  transition: "glass",      // (необязательно) переход «сквозь стекло», как у финала
  effects: {                // (необязательно)
    snow: true,             //   снег поверх слайда
    flicker: true           //   мерцание тёплого света; можно { x: 54, y: 52 } — центр пятна в % экрана
  },
  content: { ... }          // содержимое, см. шаблоны ниже
}
```

Общие поля `content`: `kicker` (надзаголовок), `title`, `subtitle`, `text` и `caption`. `text` — это строка или массив абзацев; в строке абзацы разделяются пустой строкой.

### Шаблоны

**title** — крупный заголовок и подзаголовок (обложка раздела, финал):
```js
content: {
  layout: "title",
  kicker: "Часть первая",
  title: "Новогодняя ночь",
  subtitle: "Короткая фраза под заголовком"
}
```

**text** — заголовок и 1–3 абзаца (идея, синопсис, тон):
```js
content: {
  layout: "text",
  kicker: "Сцена 02",
  title: "Окно",
  text: [
    "Первый абзац.",
    "Второй абзац."
  ]
}
```

**text-image** — текст с одной стороны, картинка-референс с другой:
```js
content: {
  layout: "text-image",
  side: "right",                               // где картинка: "right" | "left"
  kicker: "Сцена 05",
  title: "Письмо Деду Морозу",
  text: "Описание сцены.",
  images: ["assets/content/detskiy-risunok.webp"],
  caption: "Референс: детский рисунок"
}
```

**gallery** — сетка из 2–6 референсов с подписями (мудборд, раскадровка):
```js
content: {
  layout: "gallery",
  kicker: "Сцена 07",
  title: "Мудборд",
  images: [
    { src: "assets/content/nastroenie.webp", caption: "Настроение" },
    { src: "assets/content/svet.webp", caption: "Свет" },
    "assets/content/faktury.webp"              // можно и просто путь, без подписи
  ]
}
```

**palette** — цветовые плашки с HEX:
```js
content: {
  layout: "palette",
  title: "Цветовое решение",
  text: "Тёплый свет против холодной ночи.",
  colors: [
    { hex: "#16213F", name: "Ночное небо" },
    { hex: "#F2A33A", name: "Свет камина" },
    "#B3202A"                                  // можно без названия
  ]
}
```

**quote** — крупная цитата или ключевая фраза:
```js
content: {
  layout: "quote",
  kicker: "Сцена 03",
  quote: "Целый город помещается в ладони.",
  author: "Ключевая фраза"
}
```

**video** — видео с кнопкой play, без автозапуска. Пока видео играет, музыка приглушается:
```js
content: {
  layout: "video",
  kicker: "Сцена 09",
  title: "Камин",
  video: "assets/content/animatic.mp4",
  poster: "assets/content/animatic.poster.webp",  // создаётся скриптом сжатия
  caption: "Аниматик сцены"
}
```

Пустой путь (`""`) у картинки или видео выводит серую заглушку.

### Куда класть файлы

1. Положите картинки или видео в `assets_src/content/`. Подпапки можно.
2. Запустите сжатие (см. выше).
3. Укажите в `config.js` путь из `assets/content/…`. Скрипт печатает, во что превратилось каждое имя.

### Порядок слайдов

Слайды идут в том порядке, в каком стоят в массиве `slides`. Чтобы поменять порядок, переставьте объекты целиком. Движок от порядка не зависит.
- Первым должен остаться слайд `type: "cover"` — это дверь.
- Слайд с `bg: null` показывает общий план комнаты без крупного плана, как `intro`.

Чтобы добавить новую остановку:
1. Положите картинку крупного плана в `assets_src/` и запустите скрипт.
2. Добавьте объект в `slides` с `bg: "<slug>"`.
3. Разметьте для него `camera` в калибровке.

### Заменить музыку

Удалите старый аудиофайл из `assets_src/`, положите новый (mp3, wav, m4a, flac, ogg) и запустите скрипт. Громкость и длительность нарастания звука задаются в `settings.musicVolume` и `settings.musicFadeIn` в `config.js`.

### Иконка вкладки и превью ссылки

Положите в `assets_src/` два файла и запустите скрипт сжатия:

- **`favicon.png`** — иконка сайта. Лучше квадратная и с прозрачным фоном; неквадратную скрипт сам дополнит прозрачными полями. Получится:
  - `assets/icons/favicon.ico` (16, 32 и 48 px) и его копия `favicon.ico` в корне;
  - `assets/icons/icon-192.png` — для Android;
  - `assets/icons/apple-touch-icon.png` (180 px на тёмном фоне) — для iPhone.
- **`og-preview.png`** (или `.jpg`) — картинка, которую Telegram, WhatsApp и VK показывают при отправке ссылки. Лучше 1200×630 или 960×540. Скрипт сохранит её как `assets/og-preview.jpg` весом до ~300 КБ: WhatsApp не показывает превью тяжелее.

Заголовок и описание превью задаются в начале `index.html`, в тегах `og:title`, `og:description` и `description`. Держать их в `config.js` нельзя: мессенджеры читают только HTML и не выполняют JavaScript.
- Адреса в `og:url` и `og:image` должны быть полными, с доменом. Если сменится домен или заработает HTTPS, замените `http://treatmentseryak.ru/` во всех этих тегах.
- Если поменяли размер картинки превью, поправьте `og:image:width` и `og:image:height`.

Мессенджеры запоминают превью надолго. Чтобы обновить его после изменений:
- **Telegram:** отправьте ссылку боту `@WebpageBot`;
- **VK:** откройте `https://vk.com/dev/pages.clearCache` и укажите адрес сайта;
- **WhatsApp:** обновляется сам, иногда через сутки. Для проверки можно добавить к ссылке `?v=2`.

## Калибровка камеры

Откройте `index.html?debug=1` или нажмите `D` на любом слайде.

**Мастер-кадр:**
- выберите остановку в списке или кликните по её рамке;
- нарисуйте рамку мышью — она всегда 16:9;
- тяните рамку внутри, чтобы сдвинуть; колесо или `+`/`−` меняют масштаб; стрелки сдвигают, с `Shift` крупнее; `Tab` переключает на следующую остановку;
- пунктиром показано, что реально попадёт в кадр на текущем экране;
- в превью справа можно наложить крупный план ползунком и сверить композицию.

**Дверь:**
- `door.rect` — полотно двери, вырезается и поворачивается на петлях;
- `door.posterRect` — кадр камеры на обложке, 16:9;
- `door.paperRect` — лист плаката, область под заголовок;
- тут же выбирается сторона петель.

«Показать остановку» закрывает калибровку и мгновенно открывает эту остановку на весь экран. `D` возвращает обратно.

Разметка сохраняется в браузере как черновик. Чтобы перенести её в проект, нажмите **«Скопировать конфиг»** и замените в конце `config.js` блок `window.CONFIG.calibration = …` целиком. Этот блок перекрывает `camera` у слайдов и координаты двери.

## Настройки (`config.js → settings`)

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `kenBurns` | `true` | медленный дрейф крупного плана на остановке |
| `kenBurnsScale`, `kenBurnsDuration` | `1.03`, `20` | насколько и за сколько секунд |
| `musicVolume`, `musicFadeIn` | `0.5`, `2.5` | громкость музыки и нарастание в секундах |
| `wheelThreshold`, `wheelReset` | `60`, `200` | чувствительность колеса и тачпада |
| `cooldown` | `400` | пауза ввода после перехода, мс |
| `effects` | `true` | снег, мерцание, параллакс; `false` выключает всё |
| `reducedMotion` | `"ignore"` | реакция на системную настройку «уменьшить движение», см. ниже |

### «Уменьшить движение» и упрощённый режим

В упрощённом режиме полёты камеры заменяются простыми кроссфейдами, эффекты выключаются, и сайт листается как обычная презентация.

Системная настройка «уменьшить движение» (`prefers-reduced-motion`) у многих включена без их ведома:
- **Windows:** выключены «Параметры → Специальные возможности → Визуальные эффекты → Эффекты анимации» или выбран режим «наилучшее быстродействие»;
- **Android:** «Удалить анимацию», её же включают некоторые режимы энергосбережения;
- **iPhone:** «Универсальный доступ → Движение → Уменьшение движения».

Поэтому по умолчанию (`reducedMotion: "ignore"`) она не учитывается, и полёты камеры видят все. Другие значения:
- `"respect"` — упрощённый режим только у тех, у кого включена системная настройка;
- `"always"` — упрощённый режим у всех.

Для проверки режим можно переключить прямо в адресе: `index.html?motion=reduce` — упрощённый, `index.html?motion=full` — полный.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него проект: `index.html` должен лежать в корне.
   - Папку `assets_src/` (около 47 МБ исходников) можно не загружать, сайту она не нужна. Для этого добавьте строку `assets_src/` в файл `.gitignore`.
2. В репозитории откройте **Settings → Pages**.
3. В **Source** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, затем **Save**.
4. Через минуту-две сайт появится по адресу `https://<имя>.github.io/<репозиторий>/`.

Файл `.nojekyll` в корне уже есть: он отключает обработку Jekyll, и GitHub отдаёт файлы как есть.

Если подключён свой домен, включите в **Settings → Pages** галочку **Enforce HTTPS**. Без HTTPS браузер помечает сайт как «Не защищено», а кнопка «Скопировать конфиг» в калибровке не может писать в буфер обмена (текст тогда показывается в поле для ручного копирования).

После правок в `config.js` браузер может показать старую версию из кэша. Помогает жёсткое обновление: `Ctrl+F5`.

## Совместимость

- Chrome и Edge (актуальные): основная платформа, проверено.
- Firefox, Safari (macOS, iOS): поддерживаются, но в ходе разработки не проверялись. Прогоните их перед показом.
- На iPhone полноэкранный режим (`F`) недоступен: это ограничение Safari.
